# AI企业落地团队介绍

面向企业展示团队定位、成员能力、产品案例、合作边界与联系方式的静态网站。

- 在线访问：https://fhjkuyku.github.io/ai-enterprise-team-profile/
- GitHub 仓库：https://github.com/fhjkuyku/ai-enterprise-team-profile

## 本地验证

```powershell
npm install
npm test
npm run build
npm run dev
```

网站不包含表单后端、支付、会员、登录或第三方跟踪脚本。图片均已作为 Base64 嵌入 HTML；15 份产品说明 HTML 使用 Git LFS 管理。

推送到 `main` 后，持续集成与 GitHub Pages 发布工作流会自动运行。
