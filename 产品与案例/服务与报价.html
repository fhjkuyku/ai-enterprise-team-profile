Services & Pricing

AI企业落地 · 服务与报价

先分清两类计价方式，再看价格，一切就清晰了

客户版 · 通用版（不限行业）· v3

01先看懂：我们只有两种计价方式

类型怎么计价包含特点
标准品一口价，直接看表培训、诊断价格固定，不纠结
项目制先按 A/B/C 定级，再按工作量核定试点、定制系统给"起价"，诊断后出准确报价

一句话：培训、诊断是标准品，价格写死；试点、定制是项目制，先定级、再报价。

02项目制的定级标准 A / B / C（全行业通用）

试点和定制系统都用这一套标准先定级。满足该级"任一两条"即归入该级：

级别一看就懂的判断标准典型场景（举例，不限这些）
A 轻不用对接别的系统 · 数据量小 · 放云端就行 · 无硬件企业知识库问答、智能客服、会议纪要、公文/报告起草、合同条款提取、营销文案
B 中要对接 ERP / CRM / OA 等系统 · 数据多 · 要分权限经营数据看板、销售/库存预测、复杂权限知识库、与现有系统打通
C 重要接摄像头 / 设备 · 要私有化 · 涉密或高合规产线质检（视觉）、设备巡检（物联网）、集团级知识平台、涉密私有化

特别说明：为什么"知识库"有的便宜、有的上百万

同样是"企业知识库"，便宜还是贵只看三点：

  • 数据源：一个系统里的文档（便宜） vs 多个系统、多种格式要打通（贵）；
  • 文档量：几百份（便宜） vs 几十万份要处理（贵）；
  • 权限与合规：简单能用（便宜） vs 多级权限、私有化、审计留痕（贵）。
三点都简单 → A 级（便宜）；任何一点变复杂 → B / C 级（贵）。这就是同一个"知识库"价格能差几十倍的真正原因。

03第一步 · AI 培训（标准品 · 一口价）

内容：老板场讲"该不该做、能省多少、怎么起步"；员工场讲"你的岗位怎么用、动手实操、发模板"。

产品线下线上时长
公开体验课免费（受邀）免费 / 99 元1.5–2 小时
老板场内训线下 5000 元线上 2000 元线下半天 / 线上 2 小时
员工场内训线下 1 万线上 4000 元线下 1 天 / 线上 2 个半天
打包（老板+员工）线下 1.2 万线上 6000 元—

04第二步 · AI 诊断（标准品 · 一口价）

内容：访谈 → 盘点流程和数据 → 找出 3 个最值得做的场景 + 投入产出测算 → 出《AI 场景诊断报告》+ 路线图。

档位方式与时长交付价格
轻诊断线上 1 次会议 · 1–1.5 小时1 页纸结论2000 元
标准诊断线上 2–3 次视频会（每次 1–1.5 小时，跨 2–3 天分次进行）正式报告5000 元
标准诊断线下 1 天上门访谈正式报告1 万
深度诊断线下为主 · 项目制 1–2 周全流程评估 + 可执行方案2 万起
关于线上诊断：线上是"按小时、分几次开会"，不是开一整天会——所以没有"线上持续一天"的说法；只有线下才是"1 天上门"。

05第三步 · AI 试点（项目制 · 按 A/B/C 定级）

内容：拿贵公司真实数据，做出 1 个场景的"最小可用版"，让您亲眼看到效果，再决定要不要放大。

级别起价周期交付方式典型场景
A 轻2 万起2–4 周线上 云端知识库问答、智能客服、纪要、公文/报告起草、合同条款提取
B 中5 万起4–6 周线上 云端 + 系统对接经营看板、销售/库存预测、复杂权限知识库
C 重12 万起6–8 周线下 现场部署产线质检（视觉）、设备巡检、涉密私有化
关于数据安全：涉及内部数据或涉密要求，可改为私有化部署（数据不出企业），费用在定级基础上另议。

06第四步 · 定制系统（项目制 · 按 A/B/C 定级）

一个"定制系统"包含：需求分析与方案设计、系统开发（含 AI 能力）、与现有系统打通、数据整理与知识库建设、部署（云端 / 私有化 / 本地化任选）、测试验收、培训辅导、上线陪跑（3–6 个月）、年度运维（可选）。

级别起价适用部署方式
A 轻8 万起1 个场景做深（如知识库、智能客服）线上 云 / 线下 私有化
B 中25 万起3–5 个场景，需对接现有系统线上 云 / 线下 私有化
C 重60 万起集团级、硬件、多子公司集成、涉密线下 私有化 / 本地化为主

年度运维 / 陪跑

  • 按系统费用的 10% / 年，或固定 2–5 万 / 年（按规模，含问题响应、小需求迭代、安全巡检、季度回访）。
最终价怎么定：先按 A/B/C 定级得到"起价"，再按"实际工作量（人天）"核定，诊断之后给出准确、透明的报价单，不会拍脑袋。

07线上 vs 线下，怎么选

维度线上线下
费用更低（约为线下 5–6 折）更高
交付视频会议 / 直播 / 云端部署上门 / 现场 / 动手实操
适合外地、分公司多、预算有限、内容型（培训 / 知识库 / 文档处理）本地、重视实操和仪式感、涉及硬件设备 / 涉密数据
建议：培训——本地建议线下（有仪式感、能动手），外地或补课用线上；诊断——本地要实地看流程用线下，异地初步了解用线上（小时级）；试点 / 定制——知识库、文档、客服等内容型可云端线上，涉及硬件设备、涉密数据的必须线下私有化。

08付款方式

服务付款节点
培训 / 诊断（标准品）预付，或预付 50% + 结束 50%
试点（项目制）启动时付 50%，验收后付 50%
定制系统（项目制）签约 30% + 中期 30% + 验收 30% + 质保金 10%

具体以合同为准，每个项目都会先给明确的报价单和验收标准。已付的培训、诊断费用，可在后续合作中全额抵扣。

09常见问题

  1. 我们不懂 AI，能做吗？——不需要懂，从"培训"开始一步步带您走，全程说人话。
  2. 试点万一没效果怎么办？——试点就是"花小钱先验证"，不行就及时止损，比直接上大系统更稳妥。
  3. 为什么知识库价格差这么多？——看三点：数据源（一个还是多个）、文档量（几百份还是几十万份）、权限与合规（简单还是私有化）。三点越复杂越贵。
  4. 线上诊断怎么算时间？——按小时、分几次视频会，不是开一整天会；只有线下才是"1 天上门"。
  5. 你们不限定行业吗？——不限，任何行业都能做；上面场景只是举例，我们会按您的实际业务来定制。
