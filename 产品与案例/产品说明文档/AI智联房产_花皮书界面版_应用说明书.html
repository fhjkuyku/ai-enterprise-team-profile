PROP AI SCREEN GUIDE

AI 智联房产应用说明书
界面版花皮书

基于当前应用界面重新阐述：从 IP 建档、内容生产、数字人视频、获客运营，到模型/API 配置与诊断。截图均来自脱敏演示环境，不包含真实密钥、客户数据或本机路径。

  1. 1先看左侧导航IP 主线、生产、资产、工具、系统是用户每天要走的完整路线。
  2. 2再看内容工厂这是最高频入口，负责把客户问题和楼盘素材变成脚本。
  3. 3最后看配置页模型、数字人、OSS 和诊断都在系统设置里闭环。
01 / PRODUCT MAP

先看全貌：这是一套房产 IP 获客工作台

这套工具的主线是：先建立 IP 档案，再用内容工厂生产脚本，随后进入数字人视频和获客运营复盘。它不只是写文案，而是把账号定位、客户筛选、内容生成、视频生产和线索承接串成一条工作流。

  1. 1左侧导航所有功能都按 IP 主线、生产、资产、工具、系统分组；用户不用记网址，从左侧点入口即可。
  2. 2内容工厂日常高频入口，从客户问题或楼盘素材生成脚本。
  3. 3AI 生成结果生成后在这里审稿、复制、导出，先审再发。
  4. 4IP 视频工厂脚本确认后选择形象和声音，提交数字人视频任务。
02 / IP PROFILE

第一步：建立 IP 档案，让 AI 知道谁在说话

IP 档案是系统的底座。它会影响每条内容的语气、案例选择、客户称呼、CTA 和合规边界。档案越清楚，后面生成的脚本越稳定。

  1. 1点左侧“新建 IP”第一次使用先从这里开始，不建议直接去内容工厂批量生成。
  2. 2理解三件事地域化表达、客群精准触达、转化动作一致，是后续脚本能否像本人说话的基础。
  3. 3开始创建档案进入表单后填写城市、片区、经验、客户画像、内容语气和不能承诺的边界。
03 / CONTENT FACTORY

第二步：在内容工厂把素材变成获客脚本

内容工厂解决的是“我有素材但不知道怎么写”的问题。用户不需要先学提示词，只要选对内容类型，填清楚客户阶段、楼盘/片区、预算和要收集的线索字段。

  1. 1阶段条看当前内容处于草稿、生成、编辑还是可生成视频状态。
  2. 2内容方向先选预算诊断、单盘/PK、区域深析、攻略避坑等方向。
  3. 3内容技法同一方向下继续细分，比如预算段诊断、高意向客户分析。
  4. 4内容素材填写标题、客户画像、原始素材、片区预算等，素材越具体越好。
  5. 5AI 生成结果生成后先人工审稿，确认事实和合规边界。
04 / CONTENT TYPE

内容类型怎么选：先看获客目标，再选 Skill

不要把所有素材都塞进同一个模板。选题时先判断这条内容的任务：拉新、建立信任、筛选客户，还是承接咨询。

内容类型适合输入主要目标线索动作
预算诊断客户预算、首付、月供、通勤、家庭阶段精准筛客让客户留下预算、片区、上班区域、家庭阶段和当前卡点
单盘/PK 测评楼盘名、价格、户型、配套、竞品判断适合/不适合让客户留下楼盘名、预算和最担心的硬伤
区域深析片区规划、库存、成交、价格信号建立专业信任让客户留下关注片区、预算和想核实的信号
攻略避坑买房误区、政策误读、风险点拉新触达让客户按自测结果留下预算、片区和阶段
成交案例脱敏成交过程、带看故事、客户反馈建立信任让类似情况客户主动咨询
评论承接评论区问题、私信问题、发布反馈线索转化沉淀追问话术和筛选字段
05 / DIGITAL HUMAN

第三步：数字人视频从内容工厂右侧提交

数字人视频不是单独功能，它接在脚本审稿之后。先确认口播稿，再选形象、声音和画幅；如果需要统一封面、字幕和身份条，再交给本地包装模板处理。

  1. 1来源选择来自内容包适合直接使用本次生成的口播稿；已有成稿可切到直接口播。
  2. 2选择 IP 形象使用前先在 IP 形象页上传或配置可用数字人。
  3. 3选择配音声音声音资产要先训练或接入平台可用声音。
  4. 4输出格式常用竖版 9:16，适合抖音、视频号、小红书。
  5. 5本地包装需要标题、身份条、关键词和统一字幕时，再开启本地模板包装。
06 / OPERATION

第四步：获客运营把每日选题和复盘接起来

获客运营页解决“今天发什么、这个月怎么持续发”的问题。它把选题、脚本、发布反馈和线索复盘放在同一条链路上。

  1. 1左侧“获客运营”团队日常排期、月度目标和内容节奏从这里进入。
  2. 2月份和任务按钮切换月份，生成或刷新当月计划。
  3. 3日历把月度计划拆成每天可执行的选题。
  4. 4今日任务查看当天目标、脚本状态和后续动作。
  5. 5反馈回流发布后的评论、私信、带看和成交反馈要回填，后续选题才会越用越准。
07 / BRAIN & KNOWLEDGE

智联大脑：把知识库变成可问、可改稿的助手

智联大脑负责“咨询、复盘、改稿、口径沉淀”等辅助场景。越多有效知识沉淀进去，团队越容易统一话术和边界。

  1. 1智联大脑入口用来做账号诊断、脚本改写、合规审查和私域话术。
  2. 2咨询模式不同模式对应不同问题，不要所有问题都用同一种问法。
  3. 3知识库文档楼盘口径、政策边界、有效话术可以沉淀在这里。
  4. 4快捷问题第一次不知道怎么问时，可以先点示例问题。
  5. 5输入框把客户问题、脚本片段或运营反馈粘贴进来，让系统结合知识库回答。
08 / API CONFIG

API 配置页：普通用户主要看模型和数字人

API 配置必须跟界面一致。用户在界面里能填写的，就按界面流程教；不要让普通用户编辑配置文件。模型配置成功后，先去运行概览或一键诊断确认。

  1. 1模型与 API 标签进入系统设置后先点这里，不要去代码里找配置。
  2. 2内容模型卡片显示当前模型和是否已配置。脚本生成、IP 主线、运营计划都依赖它。
  3. 3智能包装模型影响本地包装标题、身份条、字幕等智能处理。
  4. 4保存内容模型切换模型后要保存，并马上测试一次。
  5. 5数字人配置区数字人 Token 在这里保存，输入框留空表示不修改已有配置。
09 / TOKEN & TEST

数字人 Token：保存后必须测试

对用户来说，Token 不是“填完就结束”。正确流程是：粘贴、保存、测试、看返回结果。若测试失败，优先检查平台账号权限、服务地址和接口权益。

  1. 1Token 输入框已配置时显示“留空表示不修改”，不会把真实 Token 暴露在页面上。
  2. 2保存配置粘贴新 Token 后点击保存，系统保存到本机安全配置。
  3. 3测试数字人保存后立即测试，确认账号、权限和服务地址是否可用。
  4. 4诊断结果看“已配置未验证 / 验证可用 / 验证失败”，不要只看是否填了 Token。
10 / DIAGNOSTICS

一键诊断：判断是没配置，还是服务不可用

当用户反馈“生成不了、视频失败、上传失败”时，先跑诊断。配置问题和接口问题要分开处理，诊断通过后再看具体业务流程。

  1. 1一键诊断标签排障时先来这里，不要让用户反复刷新页面。
  2. 2开始诊断一次检查 LLM、数字人、OSS、FFmpeg、数据库。
  3. 3诊断卡片哪个失败就先处理哪个，避免盲目改提示词或重装应用。
11 / SAFE SHARING

分享前安全清单

手册可以公开分享，真实系统数据不能公开分享。尤其 API 配置页只允许展示空输入框、遮罩、占位状态或演示环境截图。

  • 可以分享：本说明书 PDF、脱敏示例截图、空白配置模板、演示素材。
  • 不要分享：真实环境配置文件、数据库目录、日志、客户素材、导出历史内容。
  • 不要截图：完整密钥、客户姓名、电话、微信号、真实成交地址、内部价格表。
  • API Key 和 Token 只在系统设置或本机配置中填写，不发给粉丝、群聊或第三方。
  • 对外讲配置时，用“模型密钥、数字人 Token、OSS 存储、账号登录”这样的普通说法。
